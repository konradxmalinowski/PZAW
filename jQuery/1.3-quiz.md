# Quiz - jQuery - kontekst historyczny

Pytania jednokrotnego wyboru. Zaznacz jedną poprawną odpowiedź, potem sprawdź się z sekcją "Odpowiedzi" na końcu.

**1. Czym jest jQuery?**
A) Językiem programowania
B) Biblioteką JavaScript do manipulacji DOM i AJAX
C) Silnikiem bazy danych
D) Frameworkiem backendowym dla Node.js

**2. Który zapis jest odpowiednikiem `document.querySelectorAll(".karta")` w jQuery?**
A) `$(".karta")`
B) `$["karta"]`
C) `jQuery.karta()`
D) `$.karta`

**3. Co zwraca `$("p")`?**
A) Pojedynczy element DOM
B) Tablicę stringów
C) Obiekt jQuery reprezentujący zestaw dopasowanych elementów
D) Wartość logiczną true/false

**4. Która metoda jQuery zmienia tekst wewnątrz elementu?**
A) `.value()`
B) `.text()`
C) `.content()`
D) `.string()`

**5. Która metoda dodaje klasę CSS do elementu?**
A) `.class()`
B) `.setClass()`
C) `.addClass()`
D) `.style()`

**6. Który fragment poprawnie podpina obsługę kliknięcia w jQuery?**
A) `$("#btn").click.on(fn)`
B) `$("#btn").on("click", fn)`
C) `$("#btn").addEventListener("click", fn)`
D) `$("#btn").event("click", fn)`

**7. Jaki jest natywny odpowiednik `.on("click", fn)` w czystym JavaScript?**
A) `element.click(fn)`
B) `element.onClick(fn)`
C) `element.addEventListener("click", fn)`
D) `element.bind("click", fn)`

**8. Do czego historycznie służyło `$.ajax()` / `$.getJSON()`?**
A) Do stylizacji elementów
B) Do komunikacji z serwerem bez przeładowania strony
C) Do tworzenia animacji CSS
D) Do walidacji formularzy

**9. Jaki jest dzisiejszy, natywny odpowiednik `$.getJSON()`?**
A) `fetch()`
B) `require()`
C) `import()`
D) `render()`

**10. Która metoda usuwa element ze strony?**
A) `.delete()`
B) `.remove()`
C) `.hide()`
D) `.clear()`

**11. Która metoda dodaje nowy element na końcu wybranego elementu?**
A) `.push()`
B) `.insert()`
C) `.append()`
D) `.add()`

**12. Który znak w kodzie najczęściej zdradza, że mamy do czynienia z jQuery?**
A) `#`
B) `$`
C) `@`
D) `%`

**13. Czym był jQuery UI?**
A) Nowszą wersją jQuery
B) Zestawem gotowych komponentów interfejsu (np. datepicker) opartym na jQuery
C) Frameworkiem do budowy API
D) Narzędziem do testowania kodu

**14. Czym był jQuery Mobile?**
A) Aplikacją mobilną do pisania kodu
B) Wersją jQuery działającą tylko w Node.js
C) Próbą dopasowania jQuery do urządzeń dotykowych i mniejszych ekranów
D) Silnikiem bazodanowym dla aplikacji mobilnych

**15. Dlaczego dziś zwykle nie zaczyna się nowych projektów w jQuery?**
A) Bo przeglądarki przestały obsługiwać JavaScript
B) Bo jej rolę przejął natywny JavaScript (querySelector, fetch) i frameworki jak React
C) Bo jQuery została wycofana i nie da się jej już pobrać
D) Bo jQuery działa tylko w Internet Explorerze

**16. Co robi poniższy kod: `$(".karta").css("color", "red")`?**
A) Usuwa wszystkie elementy z klasą "karta"
B) Zmienia kolor tekstu wszystkich elementów z klasą "karta" na czerwony
C) Dodaje nową klasę o nazwie "red"
D) Sprawdza, czy element ma kolor czerwony

**17. Jaki był głównym powodem powstania jQuery?**
A) Chęć zastąpienia HTML
B) Ujednolicenie różnic między przeglądarkami i uproszczenie pracy z DOM
C) Stworzenie nowego języka programowania
D) Zastąpienie CSS

**18. Który zapis w czystym JavaScript odpowiada `$("#naglowek")`?**
A) `document.getElementById("naglowek")`
B) `document.class("naglowek")`
C) `window.naglowek`
D) `document.tag("naglowek")`

**19. Co zwykle oznacza brak działania kodu jQuery na stronie mimo braku widocznego błędu w HTML?**
A) jQuery zawsze działa bezbłędnie
B) Skrypt jQuery mógł się nie wczytać przed uruchomieniem własnego kodu (błąd typu "$ is not defined" w konsoli)
C) Przeglądarka blokuje wyłącznie jQuery
D) To niemożliwe, jQuery nie generuje błędów

**20. Jak dziś najczęściej realizuje się w React to, co kiedyś robiono jQuery przy obsłudze kliknięcia?**
A) Przez atrybut `onClick` w komponencie i aktualizację stanu (np. `useState`)
B) Przez `$(...).on("click", ...)` wewnątrz komponentu
C) React nie obsługuje kliknięć
D) Przez plik `.ejs` z silnikiem szablonów
