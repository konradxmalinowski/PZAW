# Zadania - jQuery - kontekst historyczny

Zadania oparte wyłącznie na pliku `1-jquery-podstawy.md`. Do każdego dołącz jQuery do prostej strony HTML, np. przez CDN:

```html
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
```

## Zadanie 1 - zmiana tekstu po kliknięciu

Zrób stronę z nagłówkiem i przyciskiem. Po kliknięciu przycisku zmień treść nagłówka za pomocą `.text()`. Wskazówka: podepnij funkcję pod zdarzenie `click` metodą `.on()`.

## Zadanie 2 - wspólna klasa dla elementów

Umieść na stronie kilka elementów (np. trzy `<div>` z tekstem) należących do tej samej klasy. Za pomocą jednego selektora jQuery wybierz je wszystkie naraz i dodaj im wspólną klasę CSS zmieniającą wygląd (np. tło albo obramowanie). Wskazówka: `.addClass()` działa na całym zestawie elementów zwróconym przez `$(...)`, nie trzeba pisać pętli.

## Zadanie 3 - dane z API

Wybierz dowolne proste, publiczne API zwracające listę (np. listę postów albo użytkowników) i pobierz z niego dane przez `$.getJSON()`. Wyświetl pobrane elementy jako listę `<li>` na stronie. Wskazówka: budowanie listy elementów w pętli `forEach` po otrzymanych danych wygląda podobnie jak w przykładzie z lekcji.

## Zadanie 4 - jQuery a czysty JavaScript

Weź poniższy fragment kodu jQuery i przepisz go na czysty JavaScript (bez `$`), tak żeby robił dokładnie to samo:

```javascript
$("#status").on("click", function () {
    $(".ukryty").removeClass("ukryty");
});
```

Wskazówka: potrzebujesz odpowiednika `$("#status")` i odpowiednika `.on("click", ...)` z lekcji - oba mają swoje nazwy w natywnym JavaScript.

## Jak sprawdzić rozwiązanie

Otwórz stronę w przeglądarce i sprawdź działanie na żywo - klik powinien wywołać widoczny efekt. Jeśli coś nie działa, sprawdź w konsoli przeglądarki (F12), czy nie ma błędu w rodzaju "$ is not defined" - to znak, że skrypt jQuery z CDN nie wczytał się przed Twoim kodem.
