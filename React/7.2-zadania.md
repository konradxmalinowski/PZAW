# Zadania - Routing po stronie klienta - react-router-dom

Zadania do pliku `7-react-router.md`. Potrzebujesz tylko tego, co tam jest - `BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, `useParams`, trasa `*`, `useNavigate`.

## Zadanie 1 - dwie strony

Skonfiguruj `BrowserRouter` w `main.jsx` i zdefiniuj w `App` dwie trasy: `/` renderującą komponent `Home` (dowolny nagłówek i tekst) oraz `/about` renderującą komponent `About`. Sprawdź w przeglądarce, że zmiana adresu w pasku URL faktycznie przełącza widok.

Wskazówka: pamiętaj, że `Routes`/`Route`/`Link` muszą być renderowane wewnątrz `BrowserRouter`.

## Zadanie 2 - menu z aktywną trasą

Dodaj komponent `Menu` z dwoma linkami do stron z zadania 1, użyj `NavLink` zamiast `Link`, i dodaj klasę CSS (np. `active-link`) dla aktualnie aktywnej trasy. Umieść `Menu` w `App`, poza `Routes`, tak żeby był widoczny na każdej podstronie.

Wskazówka: `className` w `NavLink` przyjmuje funkcję z obiektem `{ isActive }`.

## Zadanie 3 - strona szczegółów produktu

Dodaj trasę `/products/:id` renderującą komponent `ProductDetails`. Wewnątrz odczytaj `id` przez `useParams()` i wyświetl je na stronie (np. "Szczegóły produktu o id: 3").

## Zadanie 4 - od listy do szczegółów

Weź listę produktów z pliku `3-listy-klucze.md` (albo napisz podobną - kilka obiektów z `id` i `title`). Każdą kartę produktu owiń w `Link` prowadzący do `/products/:id` z konkretnym `id` tego produktu. Sprawdź, że kliknięcie karty przenosi do właściwej strony szczegółów.

## Zadanie 5 - strona nieznaleziona

Dodaj komponent `NotFound` z komunikatem "Nie znaleziono strony" i podepnij go pod trasę `path="*"`. Sprawdź w przeglądarce, że wejście pod nieistniejący adres (np. `/cokolwiek`) pokazuje ten komunikat, a istniejące trasy nadal działają poprawnie.

## Zadanie 6 - znajdź błąd (przeładowanie strony)

Poniższy `Menu` "działa", ale ma błąd, który niweczy sens SPA:

```javascript
function Menu() {
    return (
        <nav>
            <a href="/">Strona główna</a>
            <a href="/products">Produkty</a>
        </nav>
    );
}
```

Znajdź błąd i popraw go tak, żeby nawigacja nie przeładowywała strony.

## Zadanie 7 - znajdź błąd (nazwa parametru)

Poniższy kod nie wyświetla `id` - w konsoli `id` wychodzi jako `undefined`. Znajdź przyczynę i popraw.

```javascript
<Route path="/products/:productId" element={<ProductDetails />} />
```

```javascript
function ProductDetails() {
    const { id } = useParams();
    return <p>Produkt: {id}</p>;
}
```

## Zadanie 8 - powrót programowy

Na stronie `ProductDetails` dodaj przycisk "Wróć do listy", który po kliknięciu przenosi użytkownika na `/products` za pomocą `useNavigate` (bez używania `Link`).

## Jak sprawdzić rozwiązania

Uruchom aplikację (`npm run dev`) i przeklikaj wszystkie trasy ręcznie: sprawdź czy adres w pasku przeglądarki się zmienia, czy przycisk "wstecz" w przeglądarce działa poprawnie, i czy odświeżenie strony na konkretnej podstronie (np. `/products/3`) nadal pokazuje właściwy widok.
