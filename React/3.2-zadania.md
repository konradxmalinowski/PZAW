# Zadania - Renderowanie list danych i klucze w React

Zadania do pliku `3-listy-klucze.md`. Potrzebujesz tylko tego, co tam było: `.map()`, `key`, komponentu `Card` z propsami z poprzedniej lekcji i minimalnego `useState` do usuwania elementu z listy.

## Zadanie 1 - lista jako zwykłe elementy

Masz tablicę:

```javascript
const movies = [
    { id: 1, title: "Incepcja", year: 2010 },
    { id: 2, title: "Matrix", year: 1999 },
    { id: 3, title: "Interstellar", year: 2014 }
];
```

Wyrenderuj ją w komponencie `App` jako listę `<ul>`, gdzie każdy film to `<li>Tytuł (rok)</li>`. Pamiętaj o `key`.

Wskazówka: `key` ustawiasz na elemencie zwracanym bezpośrednio z `.map()` - tutaj będzie to `<li>`, nie coś w jego środku.

## Zadanie 2 - ta sama lista jako komponenty

Stwórz komponent `MovieCard` przyjmujący propsy `title` i `year`, wyświetlający je w `<div>`. Zamień listę `<li>` z zadania 1 na listę `<MovieCard />`, po jednym na każdy film z tablicy.

Wskazówka: `key` idzie na `<MovieCard />`, nie do środka komponentu jako zwykły props - `MovieCard` nie ma do niego dostępu.

## Zadanie 3 - znajdź błąd (brak key)

Dostajesz fragment kodu:

```javascript
{products.map((product) => (
    <Card title={product.title} price={product.price} />
))}
```

Co się stanie po uruchomieniu tego kodu? Uruchom go u siebie (możesz dokleić do dowolnego istniejącego komponentu) i sprawdź konsolę przeglądarki. Popraw błąd.

## Zadanie 4 - znajdź błąd (zły key)

Masz listę produktów z możliwością usuwania (jak w pliku 3), ale `key` jest ustawiony na indeks z `.map()`:

```javascript
{products.map((product, index) => (
    <div key={index}>
        <Card title={product.title} price={product.price} />
        <button onClick={() => handleRemove(product.id)}>Usuń</button>
    </div>
))}
```

Dodaj do tablicy produktów pole `id` (jeśli go nie masz) i zamień `key={index}` na coś stabilnego. Zanim to zrobisz, spróbuj usunąć środkowy element listy z kilkoma produktami i zaobserwuj, czy coś działa niepoprawnie (np. dopisz `console.log` w `Card`, żeby zobaczyć które dane trafiają do którego miejsca).

## Zadanie 5 - obsługa pustej listy

Weź kod z sekcji 5 pliku 3 (lista produktów z `useState` i przyciskiem "Usuń"). Dodaj obsługę przypadku, gdy lista jest pusta - komunikat "Brak produktów do wyświetlenia" zamiast pustego miejsca po usunięciu wszystkich elementów.

## Zadanie 6 - usuwanie elementu

Rozbuduj listę z zadania 2 (`MovieCard`) o przycisk "Usuń" przy każdym filmie. Dane muszą siedzieć w `useState`, a nie w zwykłej stałej - bez tego React nie przerysuje widoku po usunięciu.

Wskazówka: wzoruj się dokładnie na `handleRemove` z pliku 3 - nowa tablica przez `.filter()`, zapisana z powrotem przez funkcję z `useState`.

## Zadanie 7 - warunkowe oznaczenie elementu

Do tablicy filmów dodaj pole `rating` (ocena, liczba). Podczas renderowania listy oznacz inaczej filmy z oceną powyżej 8 - np. dopisz obok tytułu tekst "TOP" albo ustaw inny `className` na karcie. Użyj zwykłego wyrażenia warunkowego wewnątrz JSX (operator `? :` albo `&&`), bez żadnych bibliotek do stylowania.

## Jak sprawdzić rozwiązanie

Otwórz konsolę przeglądarki (F12) przy każdym zadaniu z listą - ostrzeżenie o brakującym `key` pojawia się właśnie tam, nie jako błąd na stronie. Przy zadaniach z usuwaniem sprawdź, czy dane przy każdym elemencie zgadzają się z tym, co widziałeś przed usunięciem - to najprostszy sposób złapania złego `key`.
