# Zadania - Komponenty funkcyjne, props i kompozycja interfejsu

Zadania do pliku `2-komponenty-props.md`. Do wykonania potrzebujesz tego, co jest w tamtym pliku, oraz podstaw JSX z pliku 1 - komponenty, props, destrukturyzacja, kompozycja. Nie potrzebujesz jeszcze `.map()`, list, `key` ani `useState`.

## Zadanie 1 - komponent Card z propsami

Stwórz komponent `Ksiazka` przyjmujący trzy propsy: `tytul`, `autor` i `cena`. Komponent ma zwracać kartę z tymi trzema informacjami. Użyj go w `App` dwa razy, z różnymi danymi.

## Zadanie 2 - przepisanie na destrukturyzację

Poniższy komponent działa poprawnie, ale odwołuje się do propsów przez `props.x`. Przepisz go tak, żeby korzystał z destrukturyzacji w parametrach funkcji, bez zmiany zachowania.

```javascript
function Uzytkownik(props) {
    return (
        <div>
            <h3>{props.imie}</h3>
            <p>{props.email}</p>
        </div>
    );
}
```

## Zadanie 3 - props typu funkcja

Stwórz komponent `Przycisk` przyjmujący propsy `tekst` i `onClick`. Ma renderować `<button>` z treścią z `tekst`, wywołujący przekazaną funkcję po kliknięciu. Użyj go w `App` dwukrotnie, za każdym razem z inną funkcją przekazaną jako `onClick` (np. jedna wypisuje coś w konsoli, druga zmienia treść przez `console.log` z innym komunikatem).

Wskazówka: to jest dokładnie ten sam wzorzec co `Button` z lekcji - komponent nie wie, co się wydarzy po kliknięciu, tylko oddaje tę decyzję rodzicowi.

## Zadanie 4 - kompozycja trzech komponentów

Zbuduj prostą stronę złożoną z trzech niezależnych komponentów: `Naglowek` (przyjmuje `tytulStrony`), kilku wystąpień komponentu z zadania 1 (`Ksiazka`) i `Stopka` (przyjmuje `rok`, bez propsów pozostałych). Wszystko spinasz w `App`, który sam nie renderuje żadnej treści bezpośrednio - tylko układa komponenty i przekazuje im dane.

## Zadanie 5 - znajdź błąd (mutowanie propsa)

Poniższy komponent ma zwracać cenę po naliczeniu 10% podatku, ale kod jest napisany niepoprawnie względem zasad Reacta. Znajdź problem i popraw go, nie zmieniając wyniku działania.

```javascript
function Produkt({ cena }) {
    cena = cena * 1.1;
    return <p>Cena z podatkiem: {cena} zł</p>;
}
```

## Zadanie 6 - znajdź błąd (literówka w nazwie propsa)

Poniższy kod nie rzuca błędem, ale nic się nie wyświetla tam, gdzie powinno być imię. Znajdź przyczynę.

```javascript
function Powitanie({ imie }) {
    return <h2>Cześć, {imie}!</h2>;
}

function App() {
    return <Powitanie imię="Ola" />;
}
```

Wskazówka: porównaj dokładnie nazwę propsa w miejscu użycia komponentu z nazwą, której komponent oczekuje w destrukturyzacji.

## Zadanie 7 - jeden komponent, wiele zastosowań

Stwórz komponent `Odznaka` przyjmujący propsy `etykieta` i `kolor` (np. `"zielony"`, `"czerwony"`, `"szary"`), który wyświetla `etykieta` w `<span>` z klasą zależną od `kolor` (np. `className={"odznaka odznaka-" + kolor}`). Użyj go co najmniej trzy razy w `App`, za każdym razem z innym zestawem propsów, żeby pokazać, że ten sam komponent daje różne rezultaty w zależności od danych, które dostaje.

## Jak sprawdzić rozwiązania

Uruchom projekt (`npm run dev`) i porównaj to, co widzisz w przeglądarce, z tym, czego się spodziewałeś. Jeśli coś się nie wyświetla, sprawdź w pierwszej kolejności nazwy propsów - to najczęstsze źródło cichych błędów w tym temacie, bo React nie ostrzega przed literówką w nazwie propsa.
