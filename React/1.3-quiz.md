# Quiz - Start z React i Vite - projekt SPA od zera

20 pytań jednokrotnego wyboru. Odpowiedzi na końcu pliku.

**1. Czym jest React?**

A) Biblioteką JavaScript do budowania interfejsów użytkownika
B) Językiem programowania
C) Bazą danych
D) Serwerem HTTP

**2. Co oznacza skrót SPA?**

A) Simple Page Application
B) Static Page Architecture
C) Single Page Application
D) Server Page API

**3. Jak działa nawigacja w klasycznej stronie (bez SPA), np. w aplikacji EJS z serii Node.js?**

A) JavaScript podmienia treść bez przeładowania
B) Strona nigdy się nie zmienia
C) Dane są pobierane wyłącznie przez WebSocket
D) Przeglądarka za każdym razem wczytuje nowy plik HTML z serwera

**4. Do czego służy Vite?**

A) Do tworzenia i uruchamiania projektu React (serwer deweloperski, budowanie aplikacji)
B) Do zarządzania bazą danych
C) Do wysyłania e-maili z aplikacji
D) Do hostowania gotowej aplikacji w internecie

**5. Jakim poleceniem tworzy się nowy projekt Vite + React?**

A) `node create-react-app`
B) `npm install react`
C) `vite build`
D) `npm create vite@latest`

**6. Co znajduje się w pliku `index.html` w projekcie Vite + React?**

A) Cała treść strony zapisana jako HTML
B) Tylko pusty element `<div id="root">` i skrypt ładujący `main.jsx`
C) Kod komponentu `App`
D) Konfiguracja bazy danych

**7. Jaką rolę pełni plik `src/main.jsx`?**

A) Jest punktem wejścia - podpina komponent `App` pod element `#root`
B) Przechowuje style CSS całej aplikacji
C) Definiuje trasy routingu
D) Konfiguruje połączenie z API

**8. Czym jest JSX?**

A) Nowym językiem programowania niezależnym od JavaScriptu
B) Formatem plików konfiguracyjnych
C) Rozszerzeniem składni JavaScriptu pozwalającym pisać znaczniki podobne do HTML
D) Biblioteką do stylowania

**9. Ile elementów głównych może zwrócić komponent React?**

A) Dowolnie wiele, bez ograniczeń
B) Zawsze dokładnie dwa
C) Zero - komponent nie może nic zwracać
D) Dokładnie jeden (albo Fragment)

**10. Co pozwala zwrócić kilka elementów obok siebie bez dodawania zbędnego `<div>`?**

A) Atrybut `className`
B) Fragment (`<>...</>`)
C) Funkcja `render()`
D) Plik `vite.config.js`

**11. Dlaczego w JSX używa się `className` zamiast `class`?**

A) `className` jest krótsze
B) `class` jest słowem zarezerwowanym w JavaScripcie (klasy)
C) `class` nie istnieje w HTML
D) To tylko kwestia stylu, oba zapisy działają tak samo

**12. Jak w JSX wygląda zapis atrybutu `onclick` z HTML?**

A) `onclick`
B) `on-click`
C) `onClick`
D) `ONCLICK`

**13. Co wypisze poniższy kod?**

```javascript
const wynik = 5;
return <p>Wynik: {wynik}</p>;
```

A) Dosłowny tekst "Wynik: wynik"
B) Błąd kompilacji
C) Pusty akapit
D) "Wynik: 5"

**14. Co jest błędem w poniższym zapisie?**

```javascript
<img src="zdjecie.jpg">
```

A) Nic, to poprawny zapis w JSX
B) Brak zamykającego ukośnika - powinno być `<img src="zdjecie.jpg" />`
C) Brak atrybutu `className`
D) Zła nazwa atrybutu `src`

**15. Dlaczego nazwa własnego komponentu musi zaczynać się wielką literą?**

A) To tylko estetyczna konwencja bez znaczenia
B) React w ten sposób odróżnia komponenty od zwykłych znaczników HTML
C) JavaScript wymaga wielkiej litery we wszystkich nazwach funkcji
D) Mała litera powoduje błąd składni w każdym przypadku

**16. Co się stanie z poniższym kodem?**

```javascript
function przycisk() {
    return <button>Kliknij</button>;
}
// użycie: <przycisk />
```

A) Zostanie potraktowany jako zwykły, nieznany znacznik HTML, a nie komponent
B) Zadziała identycznie jak `<Przycisk />`
C) Spowoduje błąd instalacji zależności
D) Automatycznie zmieni nazwę na wielką literę

**17. Co można wstawić wewnątrz `{}` w JSX?**

A) Dowolną instrukcję, np. pętlę `for`
B) Tylko liczby całkowite
C) Tylko czysty tekst
D) Wyrażenie JavaScript, np. zmienną, działanie, wywołanie funkcji

**18. Jakie polecenie uruchamia serwer deweloperski Vite?**

A) `npm start`
B) `npm run build`
C) `npm run dev`
D) `npm run preview`

**19. Co robi `npm run build`?**

A) Uruchamia serwer deweloperski z podglądem na żywo
B) Instaluje zależności projektu
C) Tworzy finalną, zoptymalizowaną wersję aplikacji pod wdrożenie
D) Usuwa katalog `node_modules`

**20. Czym różni się React od pełnego frameworka serwerowego?**

A) React jest biblioteką skupioną na widoku - routing i zarządzanie stanem globalnym dokłada się osobno
B) React wymaga instalacji bazy danych, żeby cokolwiek wyświetlić
C) React nie pozwala używać JavaScriptu
D) React automatycznie generuje backend aplikacji
