# Quiz - Renderowanie list danych i klucze w React

20 pytań jednokrotnego wyboru. Zakres: plik `3-listy-klucze.md`.

**1. Jaka metoda tablicowa służy do zamiany tablicy danych na tablicę elementów JSX?**

A) `.map()`
B) `.forEach()`
C) `.filter()`
D) `.reduce()`

**2. Co musi zwrócić funkcja przekazana do `.map()`, żeby renderowanie zadziałało?**

A) Liczbę elementów tablicy
B) JSX dla każdej iteracji
C) `true` albo `false`
D) Nic - React sam to uzupełni

**3. Do czego służy prop `key` przy renderowaniu listy?**

A) Do stylowania elementu listy
B) Do przekazania danych wewnątrz komponentu
C) Do rozpoznawania przez Reacta, który element odpowiada któremu przy kolejnych renderowaniach
D) Do sortowania listy

**4. Czy `key` jest dostępny wewnątrz komponentu jako `props.key`?**

A) Tak, zawsze
B) Tak, ale tylko w komponentach klasowych
C) Zależy od wersji Reacta
D) Nie - React zabiera go dla siebie na etapie renderowania

**5. Dlaczego indeks tablicy jako `key` jest ryzykowny?**

A) Przy zmianie listy (usunięcie, dodanie, sortowanie) indeksy się przesuwają i React może źle dopasować dane do komponentów
B) React w ogóle nie pozwala użyć indeksu jako `key`
C) Powoduje błąd w konsoli i aplikacja się nie uruchomi
D) Jest wolniejszy obliczeniowo niż `id`

**6. Kiedy użycie indeksu jako `key` jest w miarę bezpieczne?**

A) Nigdy, zawsze trzeba użyć `id`
B) Gdy lista jest naprawdę statyczna - nie zmienia kolejności ani liczby elementów
C) Gdy lista ma mniej niż 10 elementów
D) Gdy komponenty w liście nie mają propsów

**7. Co się stanie, jeśli w ogóle nie dodasz `key` do elementów listy?**

A) Aplikacja się nie uruchomi
B) React automatycznie doda `key` sam
C) React wyrenderuje listę, ale pokaże ostrzeżenie w konsoli
D) Wszystkie elementy listy się zduplikują

**8. Masz kod: `{items.map((item) => { <Card title={item.title} /> })}`. Co jest z nim nie tak?**

A) Brakuje `key`
B) `.map()` powinien być zamieniony na `.forEach()`
C) `title` nie może być propsem
D) Brakuje `return` przy klamrowym ciele funkcji strzałkowej - lista będzie pusta

**9. Jaki będzie efekt użycia `.forEach()` zamiast `.map()` przy próbie renderowania listy?**

A) Nic się nie wyświetli - `.forEach()` nie zwraca żadnej wartości
B) Zadziała identycznie jak `.map()`
C) Pojawi się błąd składni
D) Wyrenderuje się tylko pierwszy element

**10. Gdzie umieszcza się `key`, gdy `.map()` zwraca `<div>` opakowujący kartę i przycisk?**

A) Na wewnętrznym komponencie karty
B) Na zewnętrznym `<div>`, bo to on jest bezpośrednio zwracany z `.map()`
C) Na przycisku
D) `key` nie jest wtedy potrzebny

**11. Jak najlepiej ustawić `key` przy renderowaniu listy obiektów z bazy danych?**

A) Losową liczbą przy każdym renderowaniu
B) Indeksem z `.map()`
C) Wartością `id` z danych
D) Tytułem elementu (`title`)

**12. Co się wyświetli, gdy tablica przekazana do `.map()` jest pusta, a nie obsłużysz tego przypadku osobno?**

A) Błąd w konsoli
B) Aplikacja się zawiesi
C) React automatycznie pokaże komunikat "Brak danych"
D) Nic - `.map()` zwróci pustą tablicę i nic się nie wyrenderuje

**13. Jak w JSX obsłużyć przypadek pustej listy, pokazując komunikat zamiast niczego?**

A) Operatorem warunkowym `? :` (albo `&&`) sprawdzającym długość tablicy
B) Nie da się tego zrobić w JSX
C) Dodając pusty element `<Card />` na sztywno
D) Ustawiając `key={null}`

**14. Masz listę produktów w `useState` i funkcję `handleRemove(id)`. Jak poprawnie usunąć element o danym `id`?**

A) `products.splice(id, 1)`
B) `setProducts(products.filter((p) => p.id !== id))`
C) `products[id] = null`
D) `delete products[id]`

**15. Dlaczego dane do usuwania z listy muszą siedzieć w `useState`, a nie w zwykłej stałej?**

A) Bo `const` nie pozwala na tablice
B) Bo `.filter()` działa tylko na danych z `useState`
C) Bo bez stanu React nie wie, że coś się zmieniło, i nie przerysuje widoku
D) To nieprawda, zwykła stała też zadziała identycznie

**16. Które z poniższych NAJLEPIEJ opisuje `key` w kontekście renderowania listy?**

A) Zwykły props przekazywany dalej do komponentu potomnego
B) Atrybut CSS służący do stylowania
C) Nazwa zmiennej użytej w `.map()`
D) Stabilny, unikalny identyfikator elementu listy używany wewnętrznie przez Reacta

**17. Masz tablicę `users` z polami `id` i `name`. Który zapis renderowania listy jest poprawny?**

A) `{users.map(u => <li key={u.id}>{u.name}</li>)}`

**18. Co się dzieje "pod spodem", gdy React ma listę z dobrym, stabilnym `key` i jeden element zostaje usunięty?**

A) Cała lista jest renderowana od zera
