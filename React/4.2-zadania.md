# Zadania - Zarządzanie stanem lokalnym - hook useState

Zadania do pliku `4-usestate.md`. Do wykonania tylko na podstawie tego, co tam było - stan, `useState`, licznik, przełącznik, input powiązany ze stanem, lista zadań, niemutowalna aktualizacja.

## Zadanie 1 - licznik z resetem

Zbuduj komponent `Counter` z trzema przyciskami: `+1`, `-1` i `Reset`. Wartość licznika trzymaj w stanie. `Reset` ma zawsze wracać do `0`, niezależnie od tego, jaka jest aktualna wartość.

Wskazówka: to niemal ten sam przykład co w lekcji, dopisujesz tylko trzeci przycisk.

## Zadanie 2 - przełącznik z licznikiem kliknięć

Zbuduj komponent z przyciskiem, który pokazuje i ukrywa fragment tekstu (tak jak `Details` z lekcji), ale dodatkowo licz, ile razy przycisk został kliknięty, i wyświetl tę liczbę obok przycisku.

Wskazówka: potrzebujesz dwóch niezależnych wartości w stanie - jednej na widoczność, drugiej na licznik kliknięć. Obie aktualizujesz w tym samym `onClick`.

## Zadanie 3 - licznik znaków

Zbuduj pole tekstowe powiązane ze stanem (tak jak `Greeting` z lekcji), które pod spodem na bieżąco pokazuje, ile znaków zostało wpisanych, np. "Wpisano: 12 znaków". Licznik ma się aktualizować przy każdym wciśniętym klawiszu, bez osobnego przycisku.

Wskazówka: nie potrzebujesz drugiego `useState` na licznik - długość tekstu możesz policzyć wprost z wartości, która już jest w stanie.

## Zadanie 4 - lista zadań z odhaczaniem

Rozbuduj `TodoApp` z lekcji o możliwość oznaczania zadania jako zrobione (np. kliknięcie w tekst zadania przekreśla go). Zrobione zadanie ma dodatkowo pole `done: true/false` w obiekcie.

Wskazówka: żeby zmienić jedno zadanie w tablicy bez mutacji, użyj `.map()` po całej tablicy - dla zadania o pasującym `id` zwróć nowy obiekt z odwróconym `done`, dla pozostałych zwróć je bez zmian.

## Zadanie 5 - lista zadań z usuwaniem

Do tej samej listy zadań dodaj przycisk usuwający pojedyncze zadanie.

Wskazówka: to zadanie, które już znasz z poprzedniej lekcji (`.filter()` po `id`) - tu ćwiczysz je razem z resztą stanu `TodoApp`.

## Zadanie 6 - znajdź błąd (mutacja stanu)

Poniższy kod ma dodawać nowy produkt do listy, ale nie działa - lista na ekranie się nie zmienia mimo klikania przycisku. Znajdź błąd i napraw go.

```javascript
function ProductList() {
    const [products, setProducts] = useState([
        { id: 1, name: "Klawiatura" }
    ]);

    function handleAdd() {
        products.push({ id: Date.now(), name: "Nowy produkt" });
        setProducts(products);
    }

    return (
        <div>
            <button onClick={handleAdd}>Dodaj produkt</button>
            <ul>
                {products.map((p) => (
                    <li key={p.id}>{p.name}</li>
                ))}
            </ul>
        </div>
    );
}
```

Wskazówka: problem jest dokładnie ten, który opisany jest w sekcji "Najczęstsze błędy" w lekcji - `.push()` nie tworzy nowej tablicy.

## Zadanie 7 - znajdź błąd (odczyt tuż po setState)

Uczeń napisał taki kod i nie rozumie, dlaczego w konsoli zawsze widzi starą wartość:

```javascript
function handleClick() {
    setCount(count + 1);
    console.log(count);
}
```

Wyjaśnij (w komentarzu albo krótkim zdaniu pod kodem), dlaczego `console.log(count)` pokazuje starą wartość, a nie tę, która właśnie została ustawiona. Nie zmieniaj działania komponentu - to zadanie na zrozumienie, nie na poprawkę.

## Zadanie 8 - formularz jednego produktu w jednym obiekcie stanu

Zbuduj komponent z dwoma polami: nazwa produktu i cena, trzymanymi w JEDNYM obiekcie stanu (`{ name: "", price: "" }`), a nie w dwóch osobnych `useState`. Pod polami wyświetl na żywo podgląd wpisanych danych, np. "Klawiatura - 199 zł".

Wskazówka: aktualizacja jednego pola obiektu w stanie wymaga rozpakowania reszty przez spread, np. `setProduct({ ...product, name: e.target.value })` - inaczej stracisz wartość drugiego pola.

## Jak sprawdzić rozwiązanie

Uruchom komponent w przeglądarce i faktycznie kliknij/wpisz to, co zadanie opisuje - jeśli wartość na ekranie się nie zmienia mimo kliknięcia, prawie zawsze oznacza to mutację stanu zamiast wywołania funkcji aktualizującej.
