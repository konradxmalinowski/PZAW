# Quiz - Komunikacja z backendem - fetch, wysyłanie plików, odbiór danych i integracja z API

Pytania jednokrotnego wyboru. Zaznacz jedną poprawną odpowiedź, potem sprawdź się z sekcją "Odpowiedzi" na końcu.

C) Każdą funkcją zadeklarowaną wewnątrz komponentu
D) Efektem wizualnym typu animacja

**7. Dlaczego funkcja przekazana bezpośrednio do `useEffect` nie może być `async`?**

A) Bo `async` jest zarezerwowanym słowem w JSX
B) Bo `async function` zawsze zwraca `Promise`, a React oczekuje braku wartości zwracanej albo funkcji sprzątającej

D) To nieprawda, funkcja przekazana do `useEffect` może być `async`

**8. Jak poprawnie użyć `async/await` wewnątrz `useEffect`?**

A) Napisać `useEffect(async () => { ... }, [])`

**16. Dlaczego `body: JSON.stringify(product)`, a nie `body: product`?**

**19. Co jest nie tak w poniższym komponencie?**

```javascript
});
```

B) Brak drugiego argumentu (tablicy zależności) - efekt uruchomi się po każdym renderze, prowadząc do pętli żądań
C) `fetch` powinien być wywołany z `await`, inaczej nie zadziała
D) `setProducts` nie może być wywołane wewnątrz `.then()`
