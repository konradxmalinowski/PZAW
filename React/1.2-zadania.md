# Zadania - Start z React i Vite - projekt SPA od zera

Zadania do pliku `1-vite-start.md`. Do wykonania potrzebujesz tylko tego, co jest w tamtym pliku - Vite, strukturę projektu, JSX, pierwszy komponent.

## Zadanie 1 - nowy projekt

Utwórz nowy projekt przez `npm create vite@latest`, wybierz szablon React i JavaScript. Zainstaluj zależności i uruchom serwer deweloperski. Otwórz adres wypisany w terminalu i sprawdź, że widzisz domyślną stronę Vite + React.

Wskazówka: jeśli terminal nie wypisuje adresu albo serwer się nie uruchamia, sprawdź czy jesteś w katalogu projektu (`cd`) przed `npm run dev`.

## Zadanie 2 - własny nagłówek

W `src/App.jsx` zmień treść tak, żeby komponent zwracał Twoje imię i klasę, do której chodzisz, zamiast domyślnej zawartości wygenerowanej przez Vite.

## Zadanie 3 - kilka zmiennych w JSX

Zadeklaruj w komponencie `App` trzy zmienne: imię, wiek oraz wynik prostego działania matematycznego (np. `wiek * 2`). Wypisz wszystkie trzy w JSX, każdą w osobnym akapicie, korzystając z `{}`.

Wskazówka: pamiętaj, że w klamrach może stać wyrażenie (np. `{wiek * 2}`), a nie instrukcja.

## Zadanie 4 - znajdź błąd (JSX)

Poniższy komponent nie skompiluje się. Znajdź błąd i popraw go, nie zmieniając niczego poza tym, co konieczne.

```javascript
function App() {
    return (
        <h1>Witaj</h1>
        <p>To jest strona główna</p>
    );
}
```

## Zadanie 5 - znajdź błąd (className i wielkość liter)

Poniższy kod ma dwa niezależne problemy. Znajdź oba.

```javascript
function powitanie() {
    return (
        <div class="box">
            <p>Cześć!</p>
        </div>
    );
}
```

Wskazówka: jeden problem dotyczy nazwy funkcji, drugi - atrybutu HTML użytego w JSX.

## Zadanie 6 - drugi komponent

Stwórz nowy plik `Stopka.jsx` z prostym komponentem funkcyjnym (bez propsów), który zwraca np. Twoje imię i rok. Zaimportuj go w `App.jsx` i wyrenderuj pod resztą treści, tak żeby na stronie widoczne były oba komponenty naraz.

## Zadanie 7 - operator warunkowy w JSX

Rozbuduj komponent `App` o zmienną logiczną (np. `czyDostepny`) i wypisz w JSX jeden z dwóch tekstów w zależności od jej wartości, korzystając z operatora warunkowego `? :` - tak jak w przykładzie z `isLoggedIn` w lekcji.

## Jak sprawdzić rozwiązania

Uruchom projekt (`npm run dev`) i sprawdź w przeglądarce, czy widzisz to, czego się spodziewałeś. Jeśli komponent się nie renderuje albo widzisz błąd na czerwonym tle, przeczytaj komunikat błędu do końca - Vite zwykle wskazuje dokładną linię i rodzaj problemu.
