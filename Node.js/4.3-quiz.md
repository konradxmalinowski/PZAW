# Quiz - Wprowadzenie do Express.js - pierwszy serwer aplikacyjny

20 pytań jednokrotnego wyboru. Odpowiedzi znajdziesz na końcu pliku - spróbuj najpierw rozwiązać quiz samodzielnie.

A) Biblioteką upraszczającą tworzenie serwerów HTTP w Node.js
B) Osobnym językiem programowania
C) Bazą danych
D) Silnikiem JavaScript zastępującym V8

**2. Co tworzy wywołanie `express()`?**

A) Nowy serwer bazy danych
B) Obiekt aplikacji, na którym definiuje się trasy
C) Nowy plik `package.json`
D) Nowy katalog `node_modules`

C) `app.get(ścieżka, fn)`
D) `app.request(ścieżka, fn)`

D) Kod statusu 200 i odpowiedni nagłówek Content-Type

B) Do zapisania danych do pliku JSON na dysku
C) Do odczytania danych z żądania
D) Do stworzenia nowej trasy

D) Ustawia tylko nagłówek, bez wysyłania treści

**7. Co zwróci `req.body` w trasie POST, jeśli w aplikacji nie włączono `express.json()`?**

A) Pusty obiekt `{}`
B) `null`
C) `undefined`
D) Dokładnie to, co wysłał klient

D) `req.body` to dane z treści żądania, `req.query` to parametry z adresu po znaku `?`

A) `"Anna"`
B) `undefined`
C) `"search=Anna"`


C) Brakuje `app.use(express.json())`

**20. Który fragment kodu poprawnie doda nowy produkt przesłany w JSON-ie do tablicy w pamięci i odpowie kodem 201?**

```javascript

    products.push(req.query);

```

```javascript

});
```

```javascript
    res.status(201).json(req.body);
```
