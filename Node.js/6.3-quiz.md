# Quiz - Renderowanie po stronie serwera - EJS

20 pytań jednokrotnego wyboru. Odpowiedzi sprawdzisz na końcu pliku.

**1. Czym jest silnik szablonów?**
A. Bazą danych przechowującą widoki
B. Narzędziem generującym HTML na podstawie szablonu i danych
C. Modułem Node.js do obsługi plików
D. Frameworkiem zastępującym Express

**2. Jak nazywa się podejście, w którym to serwer generuje gotowy HTML wysyłany do przeglądarki?**
A. CSR
B. SPA
C. SSR
D. API

**3. Które polecenie instaluje EJS w projekcie?**
A. `npm start ejs`
B. `npm install ejs`
C. `npm init ejs`
D. `node install ejs`

**4. Jak ustawia się EJS jako domyślny silnik widoków w Express?**
A. `app.use("ejs")`
B. `app.render("ejs")`
C. `app.set("view engine", "ejs")`
D. `app.engine = "ejs"`

**5. W jakim katalogu Express domyślnie szuka plików widoków?**
A. `templates/`
B. `views/`
C. `pages/`
D. `public/`

**6. Którą metodą wysyła się gotowy widok EJS jako odpowiedź?**
A. `res.send()`
B. `res.json()`
C. `res.render()`
D. `res.view()`

**7. Co jest pierwszym argumentem `res.render()`?**
A. Obiekt z danymi
B. Kod statusu HTTP
C. Nazwa pliku widoku (bez rozszerzenia)
D. Ścieżka URL

**8. Mając `res.render("index", { title: "Start" })`, jak w widoku odwołasz się do wartości "Start"?**
A. `<%= req.title %>`
B. `<%= title %>`
C. `<%= data.title %>`
D. `<%= res.title %>`

**9. Który znacznik EJS wypisuje wartość zmiennej jako bezpieczny tekst?**
A. `<% %>`
B. `<%= %>`
C. `<%- %>`
D. `<%# %>`

**10. Który znacznik EJS służy do pętli i warunków, bez wypisywania wartości?**
A. `<%= %>`
B. `<%- %>`
C. `<% %>`
D. `<%% %>`

**11. Do czego służy znacznik `<%- %>`?**
A. Do komentarzy w szablonie
B. Do wstawiania surowego HTML bez escapowania
C. Do importowania innych widoków
D. Do deklaracji zmiennych globalnych

**12. Dlaczego użycie `<%-` dla danych wpisanych przez użytkownika bywa ryzykowne?**
A. Bo `<%-` działa wolniej niż `<%=`
B. Bo pozwala wstrzyknąć obcy HTML do strony
C. Bo `<%-` nie obsługuje polskich znaków
D. Bo Express blokuje ten znacznik

**13. Co się stanie, jeśli wywołasz `res.render("produkty")`, a plik `views/produkty.ejs` nie istnieje?**
A. Express zwróci pustą stronę HTML
B. Express automatycznie utworzy brakujący plik
C. Aplikacja zwróci błąd, że nie może znaleźć widoku
D. Zostanie użyty domyślny widok `index.ejs`

**14. Mając tablicę `users` przekazaną do widoku, jak poprawnie zapiszesz pętlę wypisującą imię każdego elementu?**
A. `<%= users.forEach(user => user.name) %>`
B. `<% users.forEach((user) => { %><%= user.name %><% }) %>`
C. `for user in users: <%= user.name %>`
D. `<%- users.map(name) %>`

**15. Co trafia do widoku jako dostępne zmienne przy `res.render("index", { title: "A", count: 3 })`?**
A. Tylko `title`
B. Tylko obiekt `data` zawierający obie wartości
C. `title` i `count` jako osobne zmienne
D. Nic - trzeba je pobrać ręcznie w widoku

**16. Kto w podejściu SPA (np. React) generuje ostateczny HTML widoczny w przeglądarce?**
A. Serwer, przed wysłaniem odpowiedzi
B. Baza danych
C. JavaScript uruchomiony w przeglądarce
D. Silnik EJS

**17. W podejściu SSR strona jest "gotowa"...**
A. dopiero po wykonaniu się JavaScriptu w przeglądarce
B. od razu po otrzymaniu odpowiedzi z serwera
C. dopiero po drugim żądaniu do serwera
D. nigdy, bo SSR nie generuje pełnego HTML

**18. Które zastosowanie najlepiej pasuje do prostego podejścia SSR z EJS?**
A. Rozbudowana aplikacja z wieloma interakcjami bez przeładowań strony
B. Prosta strona informacyjna albo panel administracyjny
C. Aplikacja mobilna
D. Baza danych

**19. Dlaczego bezpośrednie sklejanie HTML-a ze zmiennymi w kodzie JavaScript (np. `"<li>" + name + "</li>"`) jest niewygodne?**
A. Bo Node.js tego nie obsługuje
B. Bo szybko robi się nieczytelne przy większej ilości HTML-a
C. Bo Express blokuje taki kod
D. Bo wymaga instalacji dodatkowej biblioteki

**20. Jaki jest efekt błędu polegającego na niezamknięciu nawiasu funkcji strzałkowej w pętli EJS (np. brak `}` w drugim znaczniku `<% }) %>`)?**
A. Express po prostu zignoruje pętlę
B. Strona wyrenderuje się bez listy elementów
C. Wystąpi błąd składni przy renderowaniu widoku
D. Zmienna `users` zostanie automatycznie naprawiona
