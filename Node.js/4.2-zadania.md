# Zadania - Wprowadzenie do Express.js - pierwszy serwer aplikacyjny

Zadania do samodzielnego wykonania po lekcji o podstawach Express. Do rozwiązania wystarczy wiedza z tej lekcji oraz z lekcji 1-3 (Node.js, npm, moduły, `fs`, `path`, moduł `http`). Nie używaj `req.params` ani `express.Router()` - to temat kolejnej lekcji, tutaj trzymamy się `app.get`, `app.post`, `req.body`, `req.query` i podstawowego middleware.

## Zadanie 1: serwer z listą filmów

Zainstaluj Express w nowym projekcie i napisz serwer z trasą `GET /` zwracającą tekst powitalny oraz trasą `GET /api/movies` zwracającą jako JSON tablicę kilku filmów (obiekty z `id`, `tytul`, `rok`).

## Zadanie 2: dodawanie filmu przez POST

Rozbuduj serwer z zadania 1 o trasę `POST /api/movies`, która odbiera nowy film z `req.body` i dodaje go do tablicy w pamięci. Pamiętaj o włączeniu `express.json()` - bez tego `req.body` będzie `undefined`. Endpoint (czyli ta konkretna trasa - adres razem z metodą HTTP) ma odpowiadać kodem `201` i zwracać dodany film.

## Zadanie 3: wyszukiwanie przez req.query

Dodaj do `GET /api/movies` obsługę parametru `req.query.rok` - jeśli zostanie podany w adresie (np. `/api/movies?rok=2010`), serwer ma zwrócić tylko filmy z tego roku. Jeśli parametr nie został podany, zwróć całą listę.

## Zadanie 4: formularz kontaktowy

Napisz prosty formularz HTML (`<form method="POST" action="/kontakt">`) z polami `imie` i `wiadomosc`, oraz serwer Express obsługujący `POST /kontakt`, który odczytuje te pola z `req.body` i wypisuje je w konsoli. Zastanów się, jakiego middleware potrzebujesz, żeby to zadziałało - to nie jest to samo middleware co przy JSON-ie.

## Zadanie 5: własny middleware logujący

Napisz middleware, które dla każdego żądania wypisuje w konsoli metodę, ścieżkę i aktualny czas (`new Date().toISOString()`), a następnie przekazuje obsługę dalej. Podłącz je do aplikacji przez `app.use()` tak, żeby działało dla wszystkich tras.

## Zadanie 6: znajdź i napraw błąd

Poniższy kod nie działa poprawnie - `req.body` zawsze jest `undefined`, mimo że klient wysyła poprawny JSON:

```javascript
const express = require("express");

const app = express();

app.post("/api/products", (req, res) => {
    console.log(req.body);
    res.status(201).json(req.body);
});

app.listen(3000);
```

Znajdź przyczynę i popraw kod.

## Zadanie 7: dwa rodzaje danych naraz

Zbuduj serwer, który obsługuje jednocześnie: `POST /api/orders` przyjmujący dane jako JSON (`express.json()`) oraz `POST /kontakt` przyjmujący dane z formularza HTML (`express.urlencoded({ extended: true })`). Upewnij się, że oba middleware są włączone i oba endpointy działają niezależnie od siebie.

## Zadanie 8: API biblioteki z pełnym CRUD w pamięci

Zbuduj serwer z tablicą książek w pamięci i trasami: `GET /api/books` (cała lista), `GET /api/books` z `req.query.autor` (filtrowanie po autorze), `POST /api/books` (dodanie nowej książki, kod `201`). Zwróć uwagę na kolejność sprawdzania warunku filtrowania - obsłuż go wewnątrz tej samej trasy `GET /api/books`, bez `req.params`.

## Jak sprawdzić swoje rozwiązanie

Trasy `GET` możesz sprawdzić bezpośrednio w przeglądarce, wpisując adres z parametrami po `?`. Trasy `POST` testuj w Postmanie albo Insomni (to darmowe programy do ręcznego wysyłania żądań HTTP - przydają się właśnie tam, gdzie zwykła przeglądarka nie wystarczy, bo nie potrafi wysłać `POST` z treścią JSON bez dodatkowego kodu) - ustaw nagłówek `Content-Type: application/json` przy wysyłaniu JSON-a, żeby `express.json()` w ogóle rozpoznało treść żądania. Jeśli `req.body` uparcie jest `undefined`, sprawdź w pierwszej kolejności, czy na pewno wywołałeś `app.use(express.json())` przed definicją trasy.
