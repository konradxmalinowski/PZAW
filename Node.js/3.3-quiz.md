# Quiz - Protokół HTTP i tworzenie serwera w Node.js bez Express

20 pytań jednokrotnego wyboru. Odpowiedzi znajdziesz na końcu pliku - spróbuj najpierw rozwiązać quiz samodzielnie.

**1. Co zawiera żądanie HTTP wysyłane przez klienta?**

A) Wyłącznie treść (body)
B) Metodę, ścieżkę, nagłówki i opcjonalnie treść
C) Wyłącznie kod statusu
D) Wyłącznie adres IP serwera

**2. Która metoda HTTP jest zwykle używana do pobierania danych bez zmiany stanu serwera?**

A) POST
B) DELETE
C) GET
D) PUT

**3. Co oznacza kod statusu 404?**

A) Serwer nie znalazł zasobu pod podaną ścieżką
B) Żądanie zostało obsłużone poprawnie
C) Błąd po stronie serwera
D) Klient nie ma uprawnień

**4. Co oznacza kod statusu 500?**

A) Zasób został utworzony
B) Błąd po stronie serwera
C) Nieprawidłowe dane od klienta
D) Przekierowanie

**5. Jaki kod statusu zwraca się zwykle po udanym utworzeniu nowego zasobu przez POST?**

A) 200
B) 201
C) 204
D) 301

**6. Który obiekt w funkcji przekazanej do `http.createServer()` reprezentuje przychodzące żądanie?**

A) `res`
B) `server`
C) `req`
D) `http`

**7. Co się stanie, jeśli w obsłudze żądania nigdy nie wywołamy `res.end()`?**

A) Node.js sam zakończy odpowiedź po 5 sekundach
B) Serwer zwróci automatycznie kod 500
C) Klient będzie czekał na odpowiedź w nieskończoność
D) Nic - `res.end()` jest opcjonalne

**8. Z czego odczytujemy ścieżkę i metodę żądania w surowym module `http`?**

A) `req.path` i `req.type`
B) `req.url` i `req.method`
C) `res.url` i `res.method`
D) `http.url` i `http.method`

**9. Co robi poniższy fragment kodu?**

```javascript
res.writeHead(200, { "Content-Type": "application/json" });
```

A) Ustawia kod statusu i nagłówki odpowiedzi
B) Wysyła całą odpowiedź do klienta
C) Kończy żądanie
D) Parsuje dane JSON z body

**10. Dlaczego w ręcznym routingu ważne jest wstawienie `return` po obsłużeniu ścieżki?**

A) Bez tego program się nie uruchomi
B) Bez tego kod sprawdzi kolejne warunki i może spróbować wysłać odpowiedź drugi raz
C) `return` jest wymagany tylko w Expressie
D) To wyłącznie kwestia stylu, nie ma znaczenia funkcjonalnego

**11. Jakiej funkcji użyjesz, żeby zamienić tablicę obiektów JavaScript na tekst JSON przed wysłaniem w odpowiedzi?**

A) `JSON.parse()`
B) `JSON.stringify()`
C) `JSON.toText()`
D) `String(array)`

**12. Co zwróci `res.end(users)`, jeśli `users` jest tablicą obiektów (bez wcześniejszego przekształcenia)?**

A) Poprawną odpowiedź JSON
B) Błąd, bo `res.end()` nie przyjmuje gotowego obiektu/tablicy
C) Pustą odpowiedź
D) Automatycznie zamieni tablicę na JSON

**13. Dlaczego dane wysłane w body żądania POST trzeba "zbierać" przez zdarzenia `"data"` i `"end"`?**

A) Bo Node.js celowo utrudnia pracę z POST
B) Bo `req` jest strumieniem i dane mogą przychodzić w kawałkach
C) Bo to wymaganie protokołu TCP niezwiązane z Node.js
D) Nie trzeba tego robić, dane są dostępne od razu w `req.body`

**14. Kiedy dokładnie mamy pewność, że cała treść żądania POST dotarła?**

A) Zaraz po wywołaniu `http.createServer()`
B) W momencie wywołania zdarzenia `"end"` na `req`
C) W momencie wywołania zdarzenia `"data"` po raz pierwszy
D) Po wywołaniu `res.end()`

**15. Co zrobi poniższy kod, jeśli klient wyśle tekst, który nie jest poprawnym JSON-em?**

```javascript
const dane = JSON.parse(body);
```

A) Zwróci `null`
B) Zwróci pusty obiekt
C) Rzuci wyjątkiem
D) Zwróci `undefined` bez błędu

**16. Jak poprawnie obsłużyć sytuację z pytania 15, żeby serwer nie przestał działać?**

A) Owinąć `JSON.parse()` w `try/catch` i odesłać kod 400 przy błędzie
B) Zignorować możliwość błędu - Node.js sam sobie poradzi
C) Użyć `JSON.stringify()` zamiast `JSON.parse()`
D) Sprawdzić `typeof body === "string"`

**17. Jaki nagłówek informuje klienta, że odpowiedź jest w formacie JSON?**

A) `"Accept": "application/json"`
B) `"Content-Type": "application/json"`
C) `"Response-Type": "json"`
D) `"Format": "json"`

**18. Jaka jest główna wada ręcznego routingu przez ciąg `if`-ów w miarę wzrostu liczby ścieżek?**

A) Node.js nie pozwala na więcej niż 10 ścieżek
B) Kod robi się długi i coraz trudniejszy do czytania i utrzymania
C) Każdy `if` spowalnia serwer o sekundę
D) Trzeba za każdym razem restartować serwer

**19. Co się wykona po uruchomieniu poniższego kodu, jeśli żądanie trafi na ścieżkę `/kontakt`?**

```javascript
const server = http.createServer((req, res) => {
    if (req.url === "/") {
        res.end("Strona główna");
        return;
    }

    res.writeHead(404);
    res.end("Nie znaleziono");
});
```

A) Serwer zwróci "Strona główna"
B) Serwer zwróci kod 404 i tekst "Nie znaleziono"
C) Serwer się wywali błędem
D) Serwer nie odpowie w ogóle

**20. Który fragment kodu koduje kod statusu klienta jako "błąd po stronie klienta", a nie serwera?**

A) `res.writeHead(500, ...)`
B) `res.writeHead(400, ...)`
C) `res.writeHead(200, ...)`
D) `res.writeHead(301, ...)`
