# Zadania - Moduły, pliki i katalogi w Node.js

Zadania do samodzielnego wykonania po lekcji o modułach, `path`, `fs`, plikach JSON, katalogach, strumieniach i `Buffer`. Do rozwiązania wystarczy wiedza z lekcji 1 i 2. Nie potrzebujesz jeszcze Expressa ani bazy danych.

W zadaniach używaj `path.join(...)` zamiast ręcznego sklejania ścieżek. Jeśli zadanie nie mówi inaczej, korzystaj z CommonJS (`require`) oraz z metod synchronicznych albo callbackowych z modułu `fs`. Tam, gdzie zadanie wprost tego wymaga, użyj wersji opartej na `fs.promises` i `async`/`await`.

## Zadanie 1: moduł z funkcjami tekstowymi

Stwórz plik `text-utils.js` eksportujący przez `module.exports` cztery funkcje:

* `reverse(text)` - zwraca odwrócony tekst,
* `capitalize(text)` - zwraca tekst z wielką literą na początku,
* `countChars(text)` - zwraca liczbę znaków bez spacji,
* `countWords(text)` - zwraca liczbę słów.

W osobnym pliku `app.js` zaimportuj moduł przez `require("./text-utils")` i sprawdź działanie każdej funkcji na dowolnym zdaniu.

Wskazówki:

```javascript
text.split("").reverse().join("");
text.trim().split(/\s+/);
```

## Zadanie 2: ten sam moduł w ES Modules

Skopiuj rozwiązanie z zadania 1 do nowego katalogu i przepisz je na składnię ES Modules (`export` / `import`).

Wymagania:

* dodaj `"type": "module"` w `package.json`,
* przy imporcie lokalnego pliku dopisz rozszerzenie `.js`,
* użyj importu nazwanego, np. `import { reverse } from "./text-utils.js"`.

## Zadanie 3: analizator ścieżki

Napisz skrypt `path-info.js`, który przyjmuje nazwę pliku z argumentu programu:

```bash
node path-info.js raport_2026.pdf
```

Program ma wypisać:

* nazwę pliku z rozszerzeniem (`path.basename`),
* nazwę bez rozszerzenia (`path.parse(...).name`),
* rozszerzenie (`path.extname`),
* katalog, w którym plik miałby leżeć (`path.dirname` albo własna ścieżka),
* pełną ścieżkę do pliku w katalogu `dokumenty` obok bieżącego skryptu (`path.join(__dirname, "dokumenty", nazwaPliku)`).

Jeśli użytkownik nie poda nazwy pliku, wypisz komunikat:

```text
Użycie: node path-info.js nazwa-pliku
```

## Zadanie 4: notatki dopisywane do pliku

Napisz skrypt `notatki.js`, który:

1. Tworzy katalog `data`, jeśli jeszcze go nie ma.
2. Dopisuje do pliku `data/notatki.txt` nową linię z aktualną datą i treścią podaną jako argument programu.
3. Na końcu odczytuje i wypisuje całą zawartość pliku.

Przykład uruchomienia:

```bash
node notatki.js "Powtórzyć moduł fs"
```

Przykładowa linia w pliku:

```text
2026-09-12T10:15:00.000Z - Powtórzyć moduł fs
```

Użyj `fs.mkdirSync(..., { recursive: true })`, `fs.appendFileSync` i `fs.readFileSync`.

## Zadanie 5: konfiguracja aplikacji w JSON

Napisz skrypt `config.js`, który pracuje na pliku `data/config.json`.

Przy pierwszym uruchomieniu program ma utworzyć plik z zawartością:

```json
{
  "appName": "Moja aplikacja",
  "version": 1,
  "createdAt": "aktualna data"
}
```

Przy każdym kolejnym uruchomieniu program ma:

* odczytać istniejący JSON,
* zwiększyć `version` o 1,
* dodać lub zaktualizować pole `updatedAt`,
* zapisać plik ponownie z czytelnymi wcięciami.

Obsłuż przypadek braku pliku przez `fs.existsSync(...)` albo przez sprawdzenie `error.code === "ENOENT"` w bloku `catch`.

## Zadanie 6: lista zawartości katalogu

Napisz skrypt `ls-data.js`, który wypisuje zawartość katalogu `data`.

Wymagania:

* użyj `fs.readdirSync(..., { withFileTypes: true })`,
* przy katalogach wypisz `[DIR] nazwa`,
* przy plikach wypisz `[FILE] nazwa`,
* przy plikach dodatkowo wypisz rozmiar w bajtach (`fs.statSync`).

Przykładowy wynik:

```text
[FILE] config.json - 98 bajtów
[DIR] logs
```

## Zadanie 7: kopia, zmiana nazwy i usunięcie pliku

Napisz skrypt `porzadki.js`, który:

1. Tworzy katalog `backup`.
2. Kopiuje plik `data/notatki.txt` do `backup/notatki-kopia.txt` przez `fs.copyFileSync`.
3. Zmienia nazwę kopii na `backup/notatki-archiwum.txt` przez `fs.renameSync`.
4. Wypisuje rozmiar kopii przez `fs.statSync`.
5. Usuwa plik `backup/notatki-archiwum.txt` przez `fs.unlinkSync`.

Jeśli `data/notatki.txt` nie istnieje, wypisz czytelny komunikat i zakończ program bez błędu.

## Zadanie 8: sync kontra callback kontra Promise

Napisz trzy warianty tego samego skryptu czytającego plik tekstowy:

* wariant synchroniczny z `fs.readFileSync`,
* wariant callbackowy z `fs.readFile`,
* wariant z `fs.promises.readFile` i `async`/`await`.

W każdym wariancie dodaj komunikaty:

```javascript
console.log("Start");
// tutaj odczyt pliku
console.log("Koniec programu");
```

Porównaj kolejność komunikatów we wszystkich trzech wariantach i zapisz jednym zdaniem, dlaczego wersje callbackowa i Promise nie blokują dalszego wykonywania kodu.

## Zadanie 9: co zwraca readFile bez kodowania

Wywołaj `fs.readFileSync` na dowolnym pliku tekstowym:

* raz bez drugiego argumentu,
* raz z `"utf8"`.

Wypisz:

* oba wyniki,
* `typeof` obu wyników,
* `Buffer.isBuffer(...)` dla obu wyników,
* `.toString("utf8")` na wyniku bez kodowania.

Napisz w komentarzu w kodzie, dlaczego przy plikach tekstowych zwykle podajemy `"utf8"`.

## Zadanie 10: kopiowanie pliku strumieniem

Znajdź albo stwórz plik tekstowy o rozmiarze co najmniej kilku kilobajtów. Napisz skrypt kopiujący go do nowego pliku przy użyciu:

* `fs.createReadStream`,
* `fs.createWriteStream`,
* metody `pipe()`.

Dodaj obsługę zdarzeń:

* `"error"` na obu strumieniach,
* `"finish"` na strumieniu zapisu.

Po zakończeniu kopiowania wypisz komunikat:

```text
Kopiowanie zakończone
```

## Zadanie 11: prosta książka kontaktów w pliku JSON

Napisz skrypt `contacts.js`, który przechowuje kontakty w pliku `data/contacts.json`.

Program ma obsługiwać trzy komendy:

```bash
node contacts.js add "Jan Kowalski" "jan@example.com"
node contacts.js list
node contacts.js find jan
```

Wymagania:

* `add` dopisuje kontakt do tablicy i zapisuje plik,
* `list` wypisuje wszystkie kontakty,
* `find` wypisuje kontakty, których nazwa lub email zawiera podany tekst,
* jeśli plik JSON nie istnieje, program traktuje to jak pustą tablicę,
* dane zapisuj przez `JSON.stringify(contacts, null, 2)`.

## Zadanie 12: czyszczenie katalogu roboczego

Napisz skrypt `cleanup.js`, który usuwa katalog `temp` razem z całą zawartością.

Wymagania:

* użyj `fs.rmSync(tempPath, { recursive: true, force: true })`,
* przed usunięciem wypisz ścieżkę katalogu,
* po usunięciu wypisz komunikat `Katalog temp usunięty`,
* sprawdź działanie, tworząc wcześniej katalog `temp` z kilkoma plikami testowymi.
